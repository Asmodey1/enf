{% load i18n %} {% comment %} Кнопка переключения языка RU ⇄ EN --------------------------------- Одна кнопка: видны оба языка, текущий подчёркнут. Нажатие отправляет обычную POST-форму во встроенную вьюху Django set_language (адрес /i18n/setlang/). Вьюха записывает выбранный язык в cookie «django_language» и делает redirect обратно на страницу из поля next. Дальше LocaleMiddleware на каждом запросе читает эту cookie и включает нужный язык. У формы специально нет hx-post: шапка и подвал лежат вне #main-content, поэтому после смены языка страница должна перезагрузиться целиком. Куда положить: main/templates/main/includes/lang_switch.html Как вставить: {% include "main/includes/lang_switch.html" %} {% endcomment %} {% get_current_language as CURRENT_LANGUAGE %}
